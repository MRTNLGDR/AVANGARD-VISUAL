# Utilities

Rotinas de instalação, execução, empacotamento, auditoria, sincronização open source e validação.

- Instalação local: `install.ps1` ou `install.sh`.
- Engines: `install-engines.ps1` ou `install-engines.sh`.
- Modelos: wrappers `download-models.*`; o catálogo e o gerenciador vivem em `../models`.
- Preview/E2E: `browser_e2e.py`.
- Pacote desktop: `build-tauri.*`.

Os lançadores de um clique continuam na raiz para o usuário não precisar navegar por esta pasta.
