# Archive

Material preservado que não participa do runtime principal.

- `legacy/`: frontend estático anterior.
- `prototypes/`: shell React e tipos compartilhados ainda não integrados.
- `reports/v0.2.0/`: auditoria e relatório de testes da entrega anterior.
- `releases/`: pacotes e checksums históricos.
- `local/`: cópias redundantes e build artifacts mantidos apenas nesta máquina.

Nada neste diretório deve ser tratado como prova de inferência da versão atual.
